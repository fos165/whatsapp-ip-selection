## 住宅IP、原生IP、机房IP，WhatsApp该用哪种？

优先级很清楚：双ISP住宅IP > 历史干净的原生IP > 普通机房IP。预算充足直接上住宅IP，预算有限从干净的原生IP起步也可以，真正不能碰的是共享IP池和被营销账号用烂的地址。

三种类型的差别：

- **机房IP**：数据中心分配，IP段特征明显，风控一眼识别
- **原生IP**：由当地ISP直接分配、不经过数据中心中转的真实地址，在风控眼里属于“正常用户”的网络特征
- **双ISP住宅IP**：注册属性就是家庭宽带ISP，模拟真实家庭用户的接入方式，是现阶段跑营销账号存活率最高的类型

另一个容易选错的点是“固定”还是“轮换”。轮换代理每次请求换一个IP，适合抓公开数据和短期验证；养号和群发需要的是一号一固定IP，而且归属地要和号码注册国家一致——这也是做住宅IP代理的QuanticData给WhatsApp用户的建议：每个账号用一条粘性会话，出口国家匹配号码所在国。WhatsApp住宅IP方案的核心就两个词：静态、独享。频繁换IP的账号，比固定IP的账号死得快得多。

## 拿到IP只是第一步：注册、养号、群发的防封流程

IP把账号放进低风险起点，存活率取决于之后每一步。按阶段拆开说。

**注册阶段**

- 严格执行一号一IP。一个IP一小时内只能注册1个号，一天不超过5个，批量注册需要多IP轮着来
- 通讯录提前存约50条目标国号码，手机语言和时区与IP归属地保持一致
- 用最新版WhatsApp Business注册，权重天生比普通版高，还带问候消息、快捷回复这些功能
- 注册节奏放慢，每个点击拉开间隔；虚拟接码注册的号有被他人接码找回的风险，注册后尽快绑邮箱、开PIN码、让APP保持在线

**养号阶段**

- 7天是下限，14到15天更稳，嫌麻烦跳过这一步的人，往往第二天就封号
- 第一条消息不能由新号主动外发，用老号先发给新号、互存联系人，完成权重传递
- 每1到3天发一条日常动态；养号期不要设头像；注册2天内别登PC端和网页端
- 2天后可以被动进活跃群，总数别超3个，新号在群里只聊天不发广告

**群发阶段**

- 第一天10到20条，之后逐日递增，单日控制在150条以内
- 每条消息插入收件人名字或公司名做变量——哪怕很小的改动都会让消息指纹完全不同，这是规避“相同消息”检测最有效的单点操作
- 发送间隔设成随机浮动的几十秒，固定每30秒一条的规律性太容易被系统识别
- 首条开发信别直接甩广告，先打招呼，等对方回复再推，能明显降低被举报的概率

> 群发本身是WhatsApp官方打击的行为，上面这些动作只能降低机器识别和人为举报的概率，做不到百分之百不封。控制预期，别把全部业务押在一个号上。
